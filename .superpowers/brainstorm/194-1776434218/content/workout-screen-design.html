How it works

  • Bottom nav Workout tab routes to a new WorkoutRootScreen
  • Root screen holds an IndexedStack with both views mounted
  • AppBar segmented pill reads/writes mode to SharedPreferences
  • Default on fresh install: Simple mode
  • Switching mode is instant — no rebuild, no navigation
