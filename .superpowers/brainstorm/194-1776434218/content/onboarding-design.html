Key behaviours

  • Progress bar fills as steps complete — user always knows where they are
  • Info card updates live as user types (BMI recalculates, TDEE adjusts)
  • Gender, Activity, Goal use tap-to-select cards — no dropdowns
  • Back button returns to previous step (PageView)
  • Also accessible from Profile screen (edit profile → same wizard)
  • Activity level cards show plain-English descriptions ("desk job", "3–5 days/week")
